Find the thread.

Speak, then stop to let Lovelace transcribe the recording and pull out the ideas. Each summary timestamp takes you back to the flow.

Read and listen
Read the full transcript in paragraphs, switch to the summary, or play the recording. Select a summary timestamp to jump to the matching paragraph and seek to that moment in the audio.
Keep your sessions
Open Sessions for your recording history and keep favorites at the top. Each session’s … menu lets you open the original Markdown files or session folder, or delete a session after confirmation.
Pick up where you left off
Use Resume processing to reuse a completed transcription and generate the summary. Restart transcription… starts again from the audio and backs up previous results in the session folder.
Follow the progress
The Transcription log shows the current stage, elapsed time and Whisper output. Progress advances between stages and stays fixed while each stage runs.

Give your recordings subtitles.

Turn a talk, podcast, or screen recording into a timestamped SRT file. Choose English, Portuguese, or auto-detect and pick the audio track you want to caption.

From the desktop app

Open Captions in the sidebar. Use Browse… to choose a video or audio file, drop it into the window or paste its path, then select Generate SRT. Lovelace saves the subtitles alongside the recording and preserves the original media and any existing subtitle file.

After an OBS Studio recording

In OBS Studio 29 or later, open Tools > Scripts and add lovelace_captions.py from the Lovelace archive or the source checkout’s obs/ folder. Configure Python under Python Settings if your OBS build requires it.

Set Lovelace CLI to the executable and choose your language and audio track. For a source build, set Folder containing engines and models to the repository root. With Generate captions after recording enabled, the script writes the SRT in the background after you stop recording. For split recordings, it captions the last file OBS reports. See the OBS scripting guide.

From the command line

Run the CLI from the folder containing engines/ and models/. Audio tracks start at 1. Pass --output to choose a different SRT path.

lovelace captions "recording.mkv" --language pt --audio-track 1

Captions run on your machine with FFmpeg and Whisper.

Follow the code.

Lovelace is built to be audited from source. You can trace how it records audio, calls the local models, and links each note back to the transcript.

Capture
src/audio.rs writes microphone input to a local WAV file.
Transcription
src/pipeline.rs runs Whisper and keeps timestamped segments in JSON. src/transcript.rs joins the speech into Markdown paragraphs without timestamps or segment labels.
Summarization
src/synthesis.rs calls a local llama.cpp server at 127.0.0.1 and writes notes with source timestamps.
Captions
src/captions.rs extracts an audio track with FFmpeg and writes an SRT from Whisper timestamps. obs/lovelace_captions.py calls the CLI when OBS finishes recording.
Builds
.github/workflows/build.yml shows how the Windows and Linux binaries are tested and packaged.

Build your own version.

Get the source from the Git repository, then build the desktop app and CLI from the checkout. Cargo uses the versions in Cargo.lock.

Install rustup and x64 MinGW-w64 GCC. With MSYS2, install mingw-w64-x86_64-gcc from the MINGW64 shell and add its mingw64\bin folder to the Windows PATH. Run these commands in PowerShell from the repository root.

rustup toolchain install stable-x86_64-pc-windows-gnu --profile minimal cargo build --locked --release --features desktop --bins

The build writes lovelace.exe and lovelace-desktop.exe to target/release/. The desktop executable uses WebView2Loader.dll alongside it.

Install rustup. On Ubuntu 24.04, install the system build dependencies and run Cargo from the repository root.

sudo apt-get update sudo apt-get install build-essential pkg-config libasound2-dev libwebkit2gtk-4.1-dev libxdo-dev libayatana-appindicator3-dev librsvg2-dev rustup toolchain install stable --profile minimal cargo +stable build --locked --release --features desktop --bins

The build writes lovelace and lovelace-desktop to target/release/.

Make a first recording.

Install the desktop runtime, then choose your engines and models in the app. Connect a microphone and you’re ready to record.

Install the desktop runtime

On Windows, install Microsoft Edge WebView2 Runtime and keep the loader DLL beside the app. On Ubuntu 24.04, install the system libraries used by the CLI and desktop app.

sudo apt-get update sudo apt-get install libasound2t64 libwebkit2gtk-4.1-0 libxdo3 libayatana-appindicator3-1 librsvg2-2

Download engines and models in the app

Launch lovelace-desktop.exe on Windows or ./lovelace-desktop on Linux. For a source build, open the executable in target/release/. Go to Settings > Models and engines, choose your Whisper and summary models, and download the whisper.cpp and llama.cpp engines with Download & use.

Each download is checked against its pinned SHA-256, installed and selected automatically. You can follow the download progress, cancel it or retry after a failure. Choose a CPU or GPU backend that fits your hardware, or use Browse… to select files you already have.

Selections are saved immediately. Downloads go into the per-user data directory shown in Settings. The CLI and OBS use their own paths and flags; the manual setup below applies to them.

Manual setup for CLI and OBS

Use the extracted archive folder or the root of your source checkout. Create the paths below and install the libraries that come with each engine. Add .exe to both engine filenames on Windows. On Linux, make the engine binaries executable and keep their shared libraries available to the loader.

  • Whisper CLIengines/whisper/Release/whisper-cliChoose the CPU build for your platform.
  • llama.cpp serverengines/llama/llama-serverChoose a backend compatible with your hardware and install its required libraries and drivers. The CLI supports --cpu with a CPU build.
  • Whisper Smallmodels/ggml-small-q5_1.binMultilingual speech recognition model.

Install FFmpeg for captions

Install FFmpeg separately on your PATH. Captions use FFmpeg and your selected Whisper engine and model. Markdown summaries also use llama.cpp and a GGUF model. Restart Lovelace or OBS if it was open when you updated PATH. In the CLI, use --ffmpeg to specify a custom executable.

Record and review

In Recorder, keep System default under Audio input or choose a microphone. Use Refresh audio inputs after connecting a device. Choose English, Portuguese or Auto-detect, then select Start recording. The timer and live input-level chart show the capture; Stop saves the audio and starts processing.

Set a default language for recordings and captions under Settings > Recording and captions, then select Save settings. You can still change the language for each job. Your three most recent sessions appear in Recorder; open Sessions to review the full history and copy a transcript or summary as Markdown.

To use the CLI, run lovelace record --language en from the folder containing engines/ and models/. Invoke the binary by its path if needed. Add --cpu for CPU processing, or --audio-only to save a WAV without processing. Sessions are saved in sessoes/.

Bring your own model.

Choose models that fit your machine. Download them in Settings or browse for your own Whisper and instruction-tuned GGUF files.

Transcription with whisper.cpp

Choose a multilingual Whisper .bin for English, Brazilian Portuguese, or auto-detection. Models with .en in the filename are English-only.

The app offers Tiny, Base, Small, Medium and Large v3 Turbo. Start with Small and compare sizes as you learn what works for your recordings.

  • Whisper Baseggml-base-q5_1.bin · 59.7 MBTry this when processing time matters most.
  • Whisper Smallggml-small-q5_1.bin · 190 MBThe Lovelace default and a starting point for everyday recordings.
  • Whisper Mediumggml-medium-q5_0.bin · 539 MBTry this if Small often misses words and you can spend more time transcribing.

Summarization with llama.cpp

Choose an instruction-tuned .gguf that llama.cpp can load with a chat template. Lovelace requests structured JSON to link notes to transcript segments.

Settings offers Qwen2.5 1.5B and 3B downloads. Use Browse… for other compatible models, including the 7B option below.

  • Qwen2.5 1.5B InstructQ4_K_M · 1.12 GBA smaller download to try on a machine with limited memory. Apache 2.0.
  • Qwen2.5 3B InstructQ4_K_M · 2.1 GBThe Lovelace default. The publisher lists it under the Qwen Research license.
  • Qwen2.5 7B InstructQ4_K_M · about 4.68 GB across two filesA larger option to try for more detailed notes. Apache 2.0. Keep both files together and point --llama-model at the file ending in 00001-of-00002.gguf.

File sizes give you a starting point. Allow extra RAM or VRAM for processing and the context used during summarization.

Choose model files

In Settings > Models and engines, use Browse… to choose an existing model or engine executable. Saved selections apply to recordings, retries, restarts and captions. For managed downloads, Use model / engine switches between installed options; Delete download… removes one after confirmation and preserves external files.

The app falls back to the default paths in Local setup when no selection is saved. For CLI record and process, use --whisper-model and --llama-model to select files by path. For captions, use --whisper-model.

lovelace record --language pt --whisper-model models/ggml-base-q5_1.bin --llama-model models/qwen2.5-1.5b-instruct-q4_k_m.gguf

Choose how llama.cpp runs

The app lists engines for your operating system and architecture. Choose CPU to run on the processor, or a GPU backend supported by your hardware and drivers.

llama.cpp backends available in Settings
BackendHardware and requirements
CPUProcessor only; no GPU runtime required.
VulkanNVIDIA, AMD or Intel GPUs with a compatible Vulkan driver.
CUDASupported NVIDIA GPUs with a driver compatible with the selected CUDA version.
ROCmSupported AMD GPUs with a compatible ROCm driver; x64.
SYCLSupported Intel GPUs, including Arc and integrated graphics; x64. Linux also needs a compatible oneAPI/Level Zero runtime.
OpenVINOSupported Intel hardware; x64. GPU and NPU use needs matching drivers.
OpenCL AdrenoQualcomm Adreno with an OpenCL driver; Windows ARM64.

CUDA downloads include their companion runtime libraries. Lovelace binaries are distributed for Windows and Linux x64; ARM64 engine options are for native ARM64 builds. Linux engine packages are upstream Ubuntu builds and may need additional system libraries on other distributions.
